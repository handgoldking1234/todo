# 내일 (naeilo)

내 일(나의 할일) + 來日(다가올 날). 학생-부모 공유형 하루 스케줄·학습 관리 웹앱 프로토타입.

- 단일 HTML, 외부 CDN 의존 없음 (아이콘 인라인)
- 온보딩: 카카오/이메일 매직링크 로그인 → 아이 등록(한국 학제 학년) → 할일 추가(타이머·횟수·체크·고정일정)
- 오늘 화면: 할일 수행·완료 시점 자동 판정(제때/미리/미뤄서)·편집(미루기/수정/요일변경/삭제)·아이가 직접 할일 추가
- 부모 응원: 잘하고 있어 / 칭찬 스티커 / 한마디 → 아이 화면에 누적
- 탭: 오늘 · 스케줄 · 기록 · 가족, 그리고 설정·알림

`index.html`을 브라우저에서 열면 바로 실행됩니다.
